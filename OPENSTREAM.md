# OpenStream

Modern low-latency game streaming platform.

Targets:
- Windows x64 host
- Android ARM64 client

Features planned:
- AV1 / HEVC / H.264
- Hardware video encoding/decoding
- Low-latency UDP media transport
- Adaptive bitrate
- Audio streaming
- Gamepad input
- Keyboard and mouse input
- Touch controls
- Game discovery
- Device pairing
- Meshnet-friendly connectivity
- Modern Windows UI
- Modern Android UI
- Network diagnostics
